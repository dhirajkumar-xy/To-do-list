#  To-Do List Application - Python Internship Task 2

A simple console-based To-Do List application in Python that allows users to add, view, and remove tasks  using file handling.

### Objective
Implement a simple to-do list manager that runs in the terminal.

### Features
-  Add Task - Add new tasks to your list
-  View Tasks - Display all saved tasks with numbers
-  Remove Task - Delete any task by its number

### Tools Used
- Python 
- VS Code
- Terminal

### How to Run

python todo.py
